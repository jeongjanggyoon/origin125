# 🎭 초등학교 학급 감정 대시보드

초등학교 교실용 전자칠판 웹앱으로, 학생들이 자신의 감정을 표현하고 선생님이 학급 분위기를 파악할 수 있는 인터랙티브 도구입니다.

## ✨ 주요 기능

### 📊 최상단 네비게이션
- **날짜**: 실시간 날짜 표시 (요일 포함)
- **시간**: 실시간 시계
- **날씨**: 오늘의 날씨 정보
- **소음측정기**: 교실 소음 레벨 실시간 측정

### 🎭 탭 1: 감정 선택
- 20명의 학생이 각자 번호를 터치하여 자신의 감정 선택
- 16가지 다양한 감정 이모티콘 제공
  - 긍정적 감정: 😊 😄 🥰 😎 🤗
  - 중립적 감정: 😐 🤔 😑 😶
  - 부정적 감정: 😢 😭 😠 😰 😫 🤒
- 큰 버튼과 이모티콘으로 터치하기 쉬운 UI
- 선택 후 즉시 저장 및 시각적 피드백

### 📊 탭 2: 반 상황 대시보드
- **통계 카드**: 좋은 기분/보통/힘든 기분/미선택 학생 수
- **도넛 차트**: 전체 감정 분포 시각화
- **세부 감정 분포**: 각 감정별 학생 수 표시
- 인터랙티브 그래픽으로 한눈에 파악

### 🎨 탭 3: 감정 세계
- 학생 번호와 이모티콘이 감정에 따라 화면에서 움직임
- 긍정적 감정: 왼쪽 영역에 배치
- 중립적 감정: 중앙 영역에 배치
- 부정적 감정: 오른쪽 영역에 배치
- 애니메이션 효과로 생동감 있는 표현

### ⭐ 탭 4: 오늘의 기록
- **감정 변화 타임라인**: 최근 감정 선택 기록을 그래프로 표시
- **칭찬 릴레이**: 랜덤 칭찬 메시지 생성 (15가지)
- **선생님의 한마디**: 선생님이 학급에 메시지 작성 및 저장
- **주간 통계**: 요일별 감정 분포 막대 그래프

## 🚀 사용 방법

### 설치 불필요!
이 웹앱은 순수 HTML/CSS/JavaScript로 제작되어 별도의 설치가 필요 없습니다.

### 실행 방법

1. **방법 1: 직접 열기**
   ```
   classroom-emotion-app/index.html 파일을 더블클릭
   ```

2. **방법 2: 로컬 서버 사용**
   ```bash
   cd classroom-emotion-app
   python -m http.server 8000
   ```
   그 다음 브라우저에서 `http://localhost:8000` 접속

3. **방법 3: VS Code Live Server**
   - VS Code에서 index.html 우클릭
   - "Open with Live Server" 선택

### 전자칠판에서 사용하기

1. 전자칠판에 연결된 컴퓨터에서 index.html 파일 실행
2. 전체 화면 모드(F11)로 전환
3. 학생들이 터치하여 사용 가능

### 태블릿/스마트폰에서 사용하기

1. classroom-emotion-app 폴더를 웹 서버에 업로드
2. 또는 GitHub Pages 등을 활용하여 호스팅
3. 모든 기기에서 브라우저로 접속

## 📱 반응형 디자인

- 전자칠판 (대화면): 최적화된 레이아웃

- 스마트폰 (소화면): 모바일 친화적 UI

## 💾 데이터 저장

- **로컬 스토리지 사용**: 모든 데이터가 브라우저에 자동 저장
- **일일 초기화**: 매일 자정 이후 새로운 데이터로 시작
- **오프라인 작동**: 인터넷 연결 없이도 사용 가능 (날씨 제외)

## 🎯 교육적 효과

1. **감정 표현 능력 향상**: 학생들이 자신의 감정을 인식하고 표현
2. **학급 분위기 파악**: 선생님이 실시간으로 학급 상태 모니터링
3. **공감 능력 개발**: 친구들의 감정을 이해하고 배려
4. **데이터 리터러시**: 그래프와 차트를 통한 데이터 시각화 학습
5. **긍정적 피드백**: 칭찬 메시지로 자존감 향상

## 🔧 커스터마이징

### 학생 수 변경
`app.js` 파일에서 학생 수를 조정할 수 있습니다:
```javascript
students: Array.from({ length: 30 }, (_, i) => ({  // 20 → 30으로 변경
    number: i + 1,
    emotion: null,
    emotionType: null,
    emotionText: ''
}))
```

### 감정 추가
`index.html`의 감정 버튼 섹션에 새로운 감정을 추가:
```html
<button class="emotion-btn" data-emotion="🤩" data-type="positive">🤩 신나요</button>
```

`app.js`의 `emotionNames` 객체에 추가:
```javascript
'🤩': '신나요'
```

### 색상 변경
`styles.css`에서 색상을 자유롭게 변경:
```css
background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
```

## 🐛 문제 해결

### 소음측정기가 작동하지 않을 때
- 브라우저에서 마이크 권한 허용
- 또는 시뮬레이션 모드로 자동 전환됨

### 데이터가 사라졌을 때
- 브라우저 캐시/쿠키를 삭제하지 않도록 주의
- 매일 자정 이후 자동 초기화됨 (정상 동작)

### 차트가 표시되지 않을 때
- 인터넷 연결 확인 (Chart.js CDN 로딩 필요)
- 브라우저 새로고침 (F5)
