# Quick Start Guide

Get started with SciSciNet Explorer in 3 simple steps!

## Step 1: Install Python

Make sure you have Python 3.8 or higher installed.

**Check your Python version:**
```bash
python3 --version
```

**Don't have Python?** Download it from [python.org](https://www.python.org/downloads/)

## Step 2: Install Dependencies

Open a terminal in this folder and run:

```bash
pip install -r requirements.txt
```

Or on some systems:
```bash
pip3 install -r requirements.txt
```

## Step 3: Run the Application

### Option A: Use the launcher script (Recommended)

**On Linux/Mac:**
```bash
./run.sh
```

**On Windows:**
```
run.bat
```

### Option B: Run directly

```bash
streamlit run app.py
```

## That's It!

The application will open automatically in your browser at `http://localhost:8501`

## First Search

Try these example searches:

1. Click on the sidebar
2. Select "Papers"
3. Enter "machine learning" or "climate change"
4. Click search!
